The bar from Agents to Work

What to judge

  • Does Work → Workspaces feel like going round, not like a different screen?
  • Carousel or Deck: which reads better at full speed and at drag speed? Try reversing halfway.
  • Does the top-right sidebar button on Work still make sense now that it leads round to the left-hand list?

Rules in this prototype

  • Swipe left: Workspaces → Agents → Work → Workspaces.
  • Swipe right: the same ring backwards, so the list's right swipe brings back Work.
  • Workspaces is always the same: list on the left, Agents preview on the right. Tapping the preview or the current workspace goes to Agents.
  • Flicks commit; slow drags commit past halfway (as in mobile-swipe-controller.ts).
