Prototype Phone tabs: show only the visible pane's tabs

The idea: on the phone you swipe Workspaces ← Agent ← → Work. Today the strip under the title lists every agent tab and every work tab, whichever pane you're on. Here, the Agent pane shows only agent tabs and the Work pane only work tabs, so the strip always describes what's on screen.
How to use: drag sideways on any phone's content to swipe, or tap tabs. Below the comparison, each section is one decision; press Pick on the option you like and it flows into the Proposed phone. Picks live in the URL, so you can share them.
