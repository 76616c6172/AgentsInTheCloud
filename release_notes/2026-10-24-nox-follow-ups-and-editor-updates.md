## Features / enhancements
- Queue follow-up messages or use Steer during a turn.
- See subagents and background tasks in the Background bar.
- Use Pierre editing and highlighting with Oscura colors.
- Get prompt suggestions and Anthropic subscription support.
- Navigate file links and Files history; optionally group Changes into buckets.
- Wrap long output and use Tab in mobile terminals.
- Have `/review` commit relevant work before reviewing.
